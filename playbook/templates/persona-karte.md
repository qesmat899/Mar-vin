# Persona-Karte (Vorlage, Kapitel 1.3)

Eine Persona ist ein Psychogramm, kein Steckbrief mit Stockfoto.

```
PERSONA: „Name“, Alter
Demografie (Minimum):   Alter · Geschlecht · Wohnsituation · Beruf · verfügbares Einkommen
Situation:              Wie sieht ein normaler Tag aus?
Auftrittsmoment:        In welchem konkreten Moment tritt das Problem auf?
Wer sieht es noch:      Partner / Kollegen / Kinder / Gäste
TRIGGER EVENT:          Was hat aus „hingenommen“ ein akutes Problem gemacht?
Bisherige Versuche:     Was probiert? Was hat nicht funktioniert? Warum?
Einwände:               1. ______ 2. ______ 3. ______
Awareness-Stufe:        unaware / problem / solution / product / most aware
Identität:              Als wer will sie gesehen werden, wenn das Problem weg ist?
Sprache (wörtlich):     "______" · "______" · "______"
```

**Trennungstest:** Zwei Personas sind nur dann zwei, wenn sich Trigger, Haupteinwand oder gewünschte
Identität unterscheiden. „Frau 25–34“ vs. „Frau 35–44“ sind keine zwei Personas.
