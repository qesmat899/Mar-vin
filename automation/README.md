# automation/

Beschreibungen von wiederkehrenden Aufgaben, nach Rhythmus sortiert. **Hier liegt keine Automatik selbst**, sondern die Anweisung (Prompt) und die Festlegung, wo sie läuft.

Wo was läuft (aus `ARBEITSWEISE.md`):
- **Cowork** (Rechner an) oder **Cloud-Routine** (Rechner aus) für geplante Aufgaben
- **Hooks** in `.claude/settings.json` für Dinge beim Start/Ende einer Code-Session (bereits aktiv: `SYNC.md` laden und prüfen)
- E-Mail und Kalender: nie automatisch senden

Status aller Routinen: **keine aktiv.** Einträge unten sind Vorschläge, bis Mar zustimmt.

Faustregel aus `ARBEITSWEISE.md`: Wiederholt sich etwas dreimal, wird daraus eine Routine. Vorher nicht.
